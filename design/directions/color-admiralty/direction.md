# Portolan 設計方向：Admiralty chart（Sounding 配色版）

> 草稿。選定後改名為 `design/direction.md`，之後每個切片都照它做。範例畫面在本資料夾。

## 一句話
真正的海圖：白色水面、赭黃陸地，藍色深度帶表示影響力（越深越有影響力），洋紅標路線和提醒（和真的海圖一樣），紅色表示反對。螢幕和列印用同一組顏色。

## 字體
**IBM Plex Sans Condensed** 一個家族（400/500/600/700 + 斜體）。數字用斜體，像海圖上的水深數字。 不用第二個字體；等寬感靠 `font-variant-numeric: tabular-nums`。

| 用途 | 大小 / 字重 |
|---|---|
| 品牌字（首頁） | 50px（電腦 40px）/ 700 / 全大寫，字距 .02em |
| 頁標題（dossier 名） | 28–31px / 800 |
| 區塊標題 | 15–16px / 700 |
| 內文 | 15px / 400，行高 1.45 |
| 標籤、圖例 | 12–13px / 500–600 |
| 數字（指標） | 24–34px / 600 / 斜體 / tabular-nums |

## 圓角
2px（章）/ 6px（按鈕、欄位）/ 8px（卡片、地圖框）/ 4px（篩選）

## 立場編碼（不能只靠顏色）
海圖浮標形狀：**三角錐 = 支持**、**方塊 = 反對**、**空心圓 = 中立**、**菱形 = 事件**。影響力有兩種編碼：節點大小，加上節點正下方海床上的水深圓點（藍越深、圓越大 = 影響力越高）。Power matrix 的背景是三條深度橫帶，上面最深。

## 該做 / 不該做
- 做：洋紅只用在三件事：先聯絡路線、提醒、下一步。羅盤線用藍灰，不用洋紅。
- 做：海圖白當底，陸地赭黃只出現在海圖裡，不拿來當卡片或按鈕底色（避免變成米色 + 暖色的 AI 預設風）。
- 做：深度藍只表示影響力；支持用深綠，避免藍節點融進藍色水深。
- 不要：在藍色深度帶上放藍色元素。
- 不要：把紅色用在反對以外的地方（錯誤訊息除外，錯誤也算「擋路」）。
- 不要：用陰影或漸層；用細線和色塊分層。

## 版面
- 共同結構（三個配色都一樣，來自 Sounding）：海圖格線框（頁面上緣、電腦版四邊的黑白刻度條）、羅盤線、立場形狀、虛線連起「先聯絡的三個」、下一步卡片附來源數和 Admiralty 等級章，加上 Estimate 的 ICD 機率尺和私人聯絡人塗黑條。
- 手機 390px：照 `design/screens/` 的順序。首頁依序是品牌列 → 標題 → 6 格導覽 → dossier 卡片（含北台灣小海圖）→ 重點判斷（ICD 尺）→ 提醒 → 選 dossier。地圖頁依序是標題 → 3D 地圖/Power matrix 切換 → 團隊人脈開關 → 地圖 → 旋轉控制和圖例 → 分類 → 詳情 → 先聯絡的三個 → 全部清單。底部固定 5 個分頁。
- 電腦 1280px：上方一列放品牌、5 個分頁和 Sample data。
  - 首頁三欄 `300px | 1fr | 340px`：左欄品牌、導覽、dossier 清單和新增表單；中欄全台海圖（只放有地址的利害關係人）；右欄 dossier 卡片、重點判斷、提醒。
  - 地圖三欄 `290px | 1fr | 380px`：左欄切換、篩選、先聯絡的三個、團隊；中欄地圖撐滿高度；右欄詳情和全部清單。三欄各自捲動，頁面本身不捲。
- 間距：4px 基準。手機左右留白 16–18px，區塊間距 14px（地圖）／22px（首頁）。電腦欄內留白 18–24px。觸控目標至少 44px。
- A4 報告：794×1123，`@page{size:A4;margin:0}`，內距 42/46/32px，6px 刻度框 + 1px 內框。順序：標題框 + 品牌/可信度框 → 摘要和三個指標（含 ICD 尺）+ 固定角度地圖 → 前 5 名表格（來源編號 + 等級章）→ 進入路徑、7 天計畫 / 見面地點、風險 → 來源清單（等級章 + 查證日期）+ 分享連結。

## 元件
- **等級章**（`.stamp`）：Admiralty 等級（A1–F6）用雙框、轉 −3°、粗體 11.5px，顏色 `--stamp`。每個來源、提醒、表格的來源欄都要有。
- **ICD 機率尺**（`.icd`）：七段寬度 5/15/25/10/25/15/4，對應 almost no chance → almost certain；只亮一段，顏色 `--icd-on`。旁邊一定寫用語和區間（例：likely (55–80%)），信心度另外寫一句。
- **塗黑條**（`.redact`）：團隊人脈的聯絡人姓名一律顯示成 4.4em 的實心條，顏色 `--redact`，`aria-label="name withheld"`。
- **先聯絡**：虛線 `--route`，粗 `--route-w`，連起 P.REC 的三個；詳情面板的「Recommended action」左邊 4px `--act` 條。
- **按鈕**：主要 `--btn-bg`；`--act` 只給「下一步」相關的唯一動作。按下有回饋（「Added to tracker」、「Copied」、轉圈的重新整理）。
- 載入中、空資料、錯誤：見下方 Non-ideal state。

## 10/31 加入的元件（向知名產品借的做法）
- **手機詳情面板**（Apple Maps 地點卡；**待創辦人選**：另一個選項是照設計稿把詳情放在地圖下方，兩種都在 02-map.html 用 Details layout 切換或 `?layout=sheet|below` 預覽）：地圖頁的詳情在 1023px 以下是固定在分頁列上方的底部面板，三個高度：收合 168px（顯示「先聯絡的三個」）、一半、全高（80dvh）。點節點自動升到一半；取消選取回到收合。把手可拖、可點、可用上下鍵。
- **固定的動作列**（Felt 面板）：詳情的「View evidence」「Add to tracker」`position:sticky; bottom:0`，捲動時一直看得到。
- **Find a stakeholder**（Linear ⌘K）：combobox + listbox，⌘K / Ctrl K 或 / 開啟，上下鍵選、Enter 選取、Esc 清除；← → 轉地圖。沒有結果時給一個具體建議。
- **聚焦計數**（Kumu focus）：選取後提示「名稱：顯示 N 個直接關係，按 Esc 或再點一次恢復全部」。
- **Non-ideal state**（Blueprint）：`.nis` = 圖示 + 標題 + 一句原因 + 一兩個動作。載入中要列出一條條找到的來源和進度條；空資料給「清除篩選」；錯誤說明資料沒有遺失並給「重試」。首頁錯誤狀態 = 達到每日研究上限。預覽：任何頁面加 `?state=loading|empty|error`。

## 文字
- 介面用白話：「Contact these three first, in order」「Open stakeholder map」「Add to tracker」。航海用語只出現在視覺上，不放在按鈕。
- 不用全大寫標籤（品牌字除外）；不用 [CLIENT] 這類佔位字；查不到寫 date unverified。
- 每頁標 Sample data（範例資料時）。
