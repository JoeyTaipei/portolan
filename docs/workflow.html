這版改了什麼

兩份合成一份以「MVP 建置流程」為骨架。「Atlas 建 App 流程指南」只留產品方向、來源規則和 cmux；Expo、Agent Teams、文件 worker、evals、專家審稿、團隊人脈都移到送出之後。
網頁，不做手機 AppYC 看的是使用者和進度。網址點開就能用，不用等 App Store 審核；每次合併一分鐘內上線。版面照設計稿手機優先，可加到主畫面。
設計稿直接用 Atlas App Mockup.html：8 個畫面、真的 CSS 和範例資料。不再用 Lovable 截圖。
研究引擎Parallel 做研究，每個結論附來源；Claude API 只根據這些來源評分、寫策略。
避免看起來普通研究結論在 docs/research/generic-risks.md。寫程式前先比 4 個設計方向；每個切片檢查來源、具體的下一步、佔位字。
Spec 和 Plan整個 MVP 只寫一次，不是每個功能各寫一次。
誰下指令Claude 自己跑指令。你只負責登入、貼金鑰、做決定、找使用者、按合併。

工具：要 / 不要

工具要不要為什麼
Mac mini要主要開發機。cmux 只能在 Mac 上跑；一直插著電開著，Claude 可以整晚跑 /build auto。
cmux要兩個 Claude 並排跑（畫面、研究引擎），需要你時會通知。
Parallel要研究結果附來源（Basis），符合「每個結論都要有來源」；非同步執行，不受 Vercel 函式時間限制。
Claude API要評分、策略簡報、7 天計畫。
Playwright MCP要cmux 裡的 Claude 靠它開瀏覽器檢查畫面。桌面版有內建瀏覽器，不用它。
frontend-design skill要Anthropic 官方。做畫面時避免掉回 AI 預設風（第 3 步的設計方向、每個切片的畫面）。
Deep research skill不用目錄裡只有要另外付費 API 的（Exa、Tavily、You.com）。一次性研究 Claude 直接上網查就夠；產品裡的研究用 Parallel。
/goal、Goal Composer先不用/agent-skills:build auto 加上 plan 裡的驗收條件已經能讓 Claude 一路做完。整晚無人看管跑時才值得用。
Ghostty不用另裝cmux 就是用 Ghostty 的引擎做的。
MacBook不需要一直開著的 Mac mini 更適合長時間跑；外出時用遠端控制。
Agent Teams先不用4 天衝刺裡 token 多、隊友容易改到同一個檔案；兩個 cmux 工作區就夠。
Xcode、Expo、EAS不用網頁 App 用不到。之後要做原生 App 再看「Atlas 建 App 流程指南」。
gstack、Context7、Lovable不用原本只用到一小部分，現在有更直接的做法。

Mac mini 基本工具

你 · Mac 的「終端機」· 約 20 分鐘

Mac mini 已經有 Claude Code，所以這段大部分交給 Claude：在 Mac 的終端機輸入 claude，貼上第一步。下面其他步驟是清單，讓你核對它做了什麼；要密碼、登入或按允許的時候你來。

  1. Claude檢查並補齊 Mac mini 的工具
    先執行 claude update 確認 Claude Code 是最新版。然後檢查這台 Mac 有沒有：Homebrew、git、node（v20 以上）、gh、cmux、
Playwright MCP、frontend-design 和 agent-skills 兩個 plugin。缺的用這些指令裝，已經有的跳過：
  Homebrew：官方 install.sh；工具：brew install git node gh
  cmux：brew tap manaflow-ai/cmux && brew install --cask cmux，再 cmux hooks setup
  claude mcp add --scope user playwright -- npx @playwright/mcp@latest
  claude plugin install frontend-design@claude-plugins-official --scope user
  claude plugin marketplace add addyosmani/agent-skills
  claude plugin install agent-skills@addy-agent-skills --scope user
gh 要登入 JoeyTaipei 帳號。需要我輸入密碼、登入或按允許時告訴我。最後列出每一項的狀態。
    Homebrew 安裝會要 Mac 的登入密碼，那一步你自己在終端機輸入。
  2. 你裝 Homebrew（完成後依畫面提示貼上那兩行，再開新視窗）
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  3. 你裝 Git、Node.js、GitHub CLI，登入 GitHub
    brew install git node gh
node --version     # 要 v20 以上
gh auth login
    用 JoeyTaipei 帳號登入，atlas repo 在這個帳號下。
  4. 你Claude Code CLI 已裝好可跳過；確認桌面版也登入同一帳號
    curl -fsSL https://claude.ai/install.sh | bash
claude          # 瀏覽器登入後 /exit
  5. 你裝 cmux，讓它認得 Claude Code
    brew tap manaflow-ai/cmux
brew install --cask cmux
cmux hooks setup
    之後都在 cmux 裡開終端機。快捷鍵：⌘N 新工作區、⌘D 分割窗格、⌘⇧U 跳到需要你的窗格。
  6. 你裝 Playwright MCP 和 Addy 的 agent-skills
    claude mcp add --scope user playwright -- npx @playwright/mcp@latest
claude plugin install frontend-design@claude-plugins-official --scope user
    接著輸入 claude，在 claude 裡貼下面兩行，範圍選 User：
    /plugin marketplace add addyosmani/agent-skills
/plugin install agent-skills@addy-agent-skills
    只裝這兩個。frontend-design 是 Anthropic 官方的設計 skill，專門避免畫面看起來像 AI 預設；agent-skills 提供 spec、plan、build、ship。
  7. 你系統設定 → 能源：接電源時防止自動睡眠
    Claude 才能在你離開時繼續跑。
  8. 你（選配）從 PC 遠端用 Mac mini
    Mac：系統設定 → 一般 → 共享 → 打開「遠端登入」。PC 的 Claude 桌面版新增一個 SSH 連線指到 Mac mini，之後在 PC 上就能開跑在 Mac mini 的 session。
