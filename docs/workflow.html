這版改了什麼

改名Atlas 改叫 Portolan。程式、文件、App 裡的文字都改；設計稿上寫 ATLAS 的地方在 App 裡顯示 Portolan。GitHub repo 和本機資料夾在第 2 步改名。
網頁 App只做網頁，不做 iOS／Android App，也不上 App Store。電腦和手機瀏覽器都要好用：手機寬度照設計稿，電腦寬度用多欄版面。Xcode、Expo、EAS、TestFlight 都不用。
功能全保留設計稿的每個功能都做，包括團隊人脈圖層、網絡分頁、文件申請和專家審稿開關、觀察清單。背後要人工的部分（專家審稿、風險簡報、牽線）按鈕和紀錄是真的，由團隊親手完成。逐項清單在 design/intent.md 第 5 節。
需求文件design/intent.md 重寫：整合設計稿、「Atlas 建 App 流程」的產品方向（護城河、四種文件、方案、團隊人脈規則）和研究結論。
從 v2 保留Parallel 做研究、Claude 只根據來源寫；先比設計方向再寫程式；Spec 和 Plan 只寫一次；Claude 自己跑指令，你負責登入、貼金鑰、做決定、找使用者、按合併。
Claude Code 做法加上「怎麼帶 Claude」：一次給完整範圍和邊界、每個切片都要通過驗證才算完成、被糾正就寫進 CLAUDE.md、用 auto mode 代替一直按允許。只取 MVP 用得到的，多代理、自動審查機器人、效能爬坡都等送出之後。
連結這頁每個連結都在 10/30 確認打得開。

工具：要 / 不要

工具要不要為什麼
Mac mini要主要開發機。cmux 只能在 Mac 上跑；一直插著電開著，Claude 可以整晚跑 /build auto。
cmux要兩個 Claude 並排跑（畫面、研究引擎），需要你時會通知。
Next.js + Vercel要網址點開就能用，每個 PR 自動有 preview，合併後一分鐘內上線。
Supabase要Postgres 資料庫；只從伺服器連，每張表開 RLS。
Parallel要研究結果附來源（Basis），符合「每個結論都要有來源」；非同步執行，不受 Vercel 函式時間限制。
Claude API要評分、策略簡報、7 天計畫、會前簡報草稿、引薦草稿。
PostHog要量 YC 會問的數字：建 dossier、匯出報告、填會後回報。
Playwright MCP要cmux 裡的 Claude 靠它開瀏覽器檢查畫面。桌面版有內建瀏覽器，不用它。
frontend-design skill要Anthropic 官方。做畫面時避免掉回 AI 預設風。
agent-skills（Addy Osmani）要spec、plan、build、ship 的流程。
Xcode、Expo、EAS、TestFlight不用不做手機 App。
three.js不用地圖照設計稿用 SVG 偽 3D（project() + 拖曳），已經夠用，也容易印進 A4 報告。
Agent Teams先不用4 天衝刺裡 token 多、隊友容易改到同一個檔案；兩個 cmux 工作區就夠。
Deep research skill不用一次性研究 Claude 直接上網查就夠；產品裡的研究用 Parallel。
/goal、Goal Composer先不用/agent-skills:build auto 加上 plan 裡的驗收條件已經能讓 Claude 一路做完。
Ghostty、MacBook不用cmux 已經用 Ghostty 的引擎；一直開著的 Mac mini 比筆電適合長時間跑。
gstack、Context7、Lovable不用查文件直接讀官方網站和 node_modules/next/dist/docs/。

怎麼帶 Claude（MVP 版）

規則已寫進 CLAUDE.md

你的工作從寫程式變成定範圍、看驗證結果、做決定。下面這些已經寫進 CLAUDE.md，每個 session 都會自動讀，不用每次重講。

做法MVP 怎麼做
一次給完整範圍不要一步一步下小指令。每個切片的範圍、檔案、驗收條件都已經在 docs/plan.md，指令只要指向它。寫 spec 時用 macOS 聽寫講完整背景，比打字詳細（/voice 不支援中文）。
講清楚不能做什麼只改計畫列的檔案；不加計畫外的功能、工具函式、套件；不動 migration 和 types.ts，要越界先問。
回報要短做完最多 3 行：改了哪些檔案、測試結果、要你看的頁面。不用加「檢查一遍再改錯」這種話，只會更慢更貴。
先看計畫再動手/agent-skills:build auto 會先給計畫讓你核准。研究引擎（S3）和團隊人脈（S7）比較複雜，先用 /plan 看完再開始。
驗證才算完成每個切片都要：測試和建置通過、/verify-ui 用 Playwright 開瀏覽器截圖比對設計稿、console 沒有錯誤。修 bug 先寫會失敗的測試。
錯誤只犯一次你糾正 Claude 一次，就請它把規則用一句話加進 CLAUDE.md。用 /memory 看和整理；保持 80 行以內。個人偏好放 CLAUDE.local.md（不會進 git）。
模型和思考深度用預設模型。Spec、評分、研究引擎用 /effort high；畫面切片用預設。不用 /advisor：比較慢、也比較貴。
權限用 auto mode（Claude Code 2.1.283 以後的預設）：安全的指令自動跑，危險的會擋下或問你，不用一直按允許。金鑰只放 .env.local，不貼進對話。
審查每個 PR 跑 /code-review；S3、S7、S8 再加 /security-review（金鑰、prompt injection、上傳檔、分享連結）。最後你看過 preview 才合併。
先不用為什麼
分層 CLAUDE.md專案還小，一個根目錄的 CLAUDE.md 就夠。超過 80 行再拆到子資料夾。
多代理、上百個 subagent給大型遷移用的。MVP 兩個 cmux 工作區就夠。
自動審查機器人、GitHub Code ReviewGitHub 上的 Code Review 要 Team／Enterprise 方案；MVP 本機 /code-review 加你看 preview 就夠。
效能爬坡、claude -p 自動化沒有使用者之前沒有東西可以優化。送出後再接進每週流程。
/sandbox、容器會擋到 npm、gh、Vercel 的網路，衝刺期間很麻煩。auto mode 加上金鑰只放 .env.local 就夠；之後跑無人看管的排程任務再開。

Mac mini 基本工具

你 · Mac 的「終端機」· 約 20 分鐘

先在終端機裝 Claude Code CLI（桌面版內建的 Claude Code 不能在終端機用，cmux 需要 CLI）。之後交給 Claude 檢查和補齊；要密碼、登入或按允許的時候你來。10/30 檢查時這台 Mac mini 已經裝好 Playwright MCP、frontend-design 和 agent-skills。

  1. 你裝 Claude Code CLI，瀏覽器登入（和桌面版同一個帳號）
    curl -fsSL https://claude.ai/install.sh | bash
claude --version   # 開新視窗後確認
    說明：Claude Code 安裝。桌面版從 claude.ai/download 下載。
  2. Claude檢查並補齊工具：輸入 claude，貼上
    先執行 claude update。檢查這台 Mac 有沒有：Homebrew、git、node（v20 以上）、gh、cmux、
Playwright MCP、frontend-design 和 agent-skills 兩個 plugin。缺的用這些指令裝，已經有的跳過：
  Homebrew：官方 install.sh；工具：brew install git node gh
  cmux：brew tap manaflow-ai/cmux && brew install --cask cmux，再 cmux hooks setup
  claude mcp add --scope user playwright -- npx @playwright/mcp@latest
  claude plugin install frontend-design@anthropic-plugin-directory --scope user
  claude plugin marketplace add addyosmani/agent-skills
  claude plugin install agent-skills@addy-agent-skills --scope user
gh 要登入 JoeyTaipei 帳號。需要我輸入密碼、登入或按允許時告訴我。最後列出每一項的狀態。
    Homebrew 安裝會要 Mac 的登入密碼，那一步你自己在終端機輸入（brew.sh）。
  3. 你打開 cmux，確認它認得 Claude Code
    之後都在 cmux 裡開終端機。快捷鍵：⌘N 新工作區、⌘D 分割窗格、⌘⇧R 改名、⌘⇧U 跳到需要你的窗格。說明：cmux Getting Started。
  4. 你在 claude 裡確認 auto mode，打開不閃爍的畫面
    /tui fullscreen
    按 Shift+Tab 切換權限模式，畫面下方顯示 auto 就對了（Claude Code 2.1.283 以後是預設）。cmux 用 Ghostty 引擎，Shift+Enter 換行本來就能用。說明：權限模式 · Fullscreen。
  5. 你系統設定 → 能源：接電源時防止自動睡眠
    Claude 才能在你離開時繼續跑。臨時也可以在 cmux 另開窗格跑 caffeinate -dims，回來按 Ctrl+C。
  6. 你（選配）從別的電腦或手機看 Mac mini
    Mac：系統設定 → 一般 → 共享 → 打開「遠端登入」，PC 的 Claude 桌面版新增 SSH 連線指到 Mac mini。手機看 cmux：cmux iOS（beta）。

常見狀況

狀況處理
研究跑太久、函式逾時不要在一次請求裡跑完：建立 Parallel 工作 → 背景執行 → 頁面輪詢或用 webhook 更新進度。
來源打不開或摘錄對不上把那個案例存成測試，再請 engine 修，不然會再發生。
簡報讀起來像 ChatGPT通常缺了客戶資料和判斷。檢查「對客戶的影響」「優先順序」「建議做法」有沒有用到客戶的產品和現況；拿 08 會前簡報當範例。
A4 報告超過一頁不要縮字型硬塞；在模板裡給每段字數上限，產生文字時就遵守。
人脈對不到機構LinkedIn 的公司名常是簡稱、英文名或舊名（「中科院」「NCSIST」）。每個利害關係人存一組別名；信心不夠時讓成員確認，結果存回別名。
地圖在手機上卡先看節點數；只在畫面變動時重繪，遠處節點合併；手機上提供清單檢視。
兩條工作區改到同一個檔案回到 docs/plan.md 重新分檔案。
