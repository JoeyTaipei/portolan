# 0004 影響力分數的穩定性修正

- 狀態：**已決定**（2026-11-01，Joey：「Yes, all three」）
- 依據：`docs/research/influence-test-2026-11-01.md`（10 個利害關係人、40 次 Claude 呼叫、US$0.74）
- 細節寫在 `docs/scoring.md` §0、§2.3

## 測試看到的問題
- 引用全部正確（133 / 133 摘錄逐字找得到）。
- 明確的案例很穩定；但 10 個裡有 4 個在三次評分之間換了等級。一半的差異是同一項在「0」和「找不到來源」之間切換：找不到的項目不算進平均，所以一次切換能讓分數差到 20 分。
- 只有一項有評級時會顯示「Low 0」這種誤導的分數。

## 決定
1. **每項評級先跑 2 次，有分歧的項目才跑第 3 次取多數**（Sonnet 5.5）。S3 實測每次約 US$0.029，3 次全跑會讓 48 個實體超過 Claude US$3.5 上限（約 US$4.2）；2 次加有分歧才補，約 US$3.1。實作在 S3 的 `rate` 步驟。
2. **結構性的 0 由程式設定**：類別 ind、cap、leg 的「正式職權」和「預算控制」沒有有來源的評級時設成 0；有來源的評級照用。
3. **至少 2 項有來源的評級才給分數**，否則顯示「Not enough sourced factors」。

## 創辦人排序之後的修正（2026-11-01 晚上，Joey 選「Clarify + gatekeeper」）
- 創辦人排序和我們的分數相關度只有中等（Spearman 0.44–0.57）：立法院被低估、主承包商和驗證單位被漏掉。
- 評級表只加一句（不改權重）：立法院審議通過或刪減國防預算算「預算控制 3」。
- 試過「關卡」寫法（驗證單位、主承包商算正式職權 2、接近決策者 3），重跑後相關度反而降到 0.34–0.43：Tron Future 被抬高、AIDC 沒變。Joey 決定撤回。
- 剩下的差距是證據：創辦人知道、我們的來源沒寫的事（例如 AIDC 是國防部的航太主承包商）。之後用更好的研究查詢，或把專家意見當成有日期、有署名的來源補上。
- 費用：2 次加有分歧才補第 3 次，平均約 2.7 次，48 個實體約 US$3.8，還是超過上限。Joey 選擇**縮短送給 Claude 的摘錄**：每個實體最多 4 個最強的來源，每段摘錄取前約 1,200 字元（摘錄是原文，引用檢查照樣成立），預估每份約 US$2.5。
